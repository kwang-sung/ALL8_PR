파일 받기 
이 파일은 메모장으로는 열리지 않고, 올에잇 프롬프트 관리에서 불러와야 열립니다.

1. 위 [파일 받기]를 눌러 .a8p 파일을 내려받습니다.
2. 올에잇 왼쪽 메뉴 설정 > 프롬프트 관리로 들어갑니다.
3. 오른쪽 위 [공유파일 업로드] > [파일 선택]에서 받은 파일을 고릅니다. 프롬프트가 목록에 추가됩니다.
4. 설정 > 마켓 설정에서 계정을 열고, 전용 상품명 항목의 [내 프롬프트]에서 추가된 프롬프트를 고른 뒤 저장합니다.
