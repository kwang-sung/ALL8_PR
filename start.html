마켓 딱 1개만 연결하세요 — 스마트스토어
🟢 첫날 필수 소요 · 30분 (API 승인 대기 별도) 선행 · 마켓 입점 승인

ALL8은 마켓 8곳을 지원하지만, 처음에는 한 곳만 연결하세요. 여러 곳을 동시에 붙이면 어디서 문제가 났는지 알 수 없습니다. 하나로 전체 흐름을 익힌 뒤에 늘리는 게 훨씬 빠릅니다.

3줄 요약
  • 첫 마켓은 스마트스토어를 권합니다. 수수료가 낮고 페널티가 덜 가혹합니다.
  • 스마트스토어센터에서 API 연동용 판매자 아이디를 확인해 ALL8에 입력합니다. 시크릿 키는 없어요.
  • 연결되면 화면에 나오는 순서대로 출고지·반품지 → 수수료 → 배송 → A/S → 원산지를 채웁니다.
🤔 왜 쿠팡이 아니라 스마트스토어부터인가요?
쿠팡은 출고 기한을 어기면 셀러 점수가 바로 깎입니다. 아직 소싱·발주 리듬이 안 잡힌 첫 주에 쿠팡부터 시작하면 첫 주문에서 사고가 나기 쉽습니다. 스마트스토어로 흐름을 익히고, 익숙해진 뒤 쿠팡을 붙이세요. 쿠팡·11번가·G마켓·옥션·롯데ON·토스쇼핑 설정은 전체 매뉴얼에 마켓별로 정리돼 있습니다.
① API 키 발급 — 처음 한 번만
  1. 스마트스토어센터 로그인sell.smartstore.naver.com · 네이버 사업자 계정이 필요합니다.
  2. 왼쪽 메뉴 → 스토어 설정 → 외부앱 관리
  3. 애플리케이션 등록 → 필요한 권한 모두 선택권한을 빼놓으면 나중에 업로드가 실패합니다. 전부 체크하세요.
  4. API 연동용 판매자 아이디 확인스마트스토어는 이 아이디 하나만 입력하면 됩니다. 별도의 시크릿 키는 없어요. 네이버 검토에 1~3영업일이 걸립니다.
  5. ALL8 → 마켓 계정 설정 → 인증 정보에 붙여넣고 연결 확인"연결 확인"이 통과하면 성공입니다.

② 초보자 권장 설정값 — 이대로만 넣으세요
항목이렇게 설정
원산지 및 수입기타 — 상세 설명에 표시 (03) 선택. 국내리셀·해외구매대행 모두 이 값이 가장 무난합니다.
출고지 / 반품지실제 주소를 정확히 입력. 반품지는 "출고지와 동일" 체크로 끝내면 됩니다. 허위 입력은 마켓 제재 대상입니다.
A/S 정보필수 — 비우면 등록이 거부됩니다. 전화번호는 실제 연락처, 안내 문구는 "문자나 톡톡 문의 주시기 바랍니다".
수수료스마트스토어는 6%. 안전 마진을 두려면 7%. 이 값만큼 판매가에 자동으로 더해져 올라갑니다.
택배사 코드필수값. 계약된 택배사가 없으면 아무거나 하나 선택하세요. 비우면 상품 등록이 거부됩니다.
묶음배송 사용체크 해제. 무재고라 상품마다 배송처가 달라 묶음이 불가능합니다. 단, 한 소싱처에서만 수집했다면 사용해도 됩니다.
제주/도서산간 추가배송비제주 / 제주 외 도서산간 분리 선택 후 제주 6,000원 · 도서산간 8,000원. 도서산간은 배송편이 적어 실비가 더 듭니다.

프리셋은 "상품이 들어올 때 자동으로 이렇게 다듬어라"는 규칙 묶음입니다. 상품명 번역, 옵션명 한글화, 이미지 배경제거, 마진 계산, 배송비, 어느 마켓에 올릴지까지 전부 담깁니다. 프리셋을 걸고 수집하면 수집이 끝나는 순간 편집도 끝나 있습니다.

⚠️ 초보자가 가장 많이 하는 실수
프리셋 없이 먼저 상품을 100개 수집한 뒤, 편집 화면에서 하나씩 고치기 시작합니다. 그러다 "이 프로그램 왜 이렇게 손이 많이 가지?" 하고 포기합니다. 순서만 바꾸면 됩니다. 프리셋 먼저입니다.

가격 · 재고 연동 설정 + 소싱기 맛보기
🟡 익숙해지면 소요 · 30분 선행 · 판매 중인 상품 있음

여기까지 오셨다면 기본기는 끝났습니다. 마지막 날은 사고를 막아주는 장치 하나와, 앞으로 쓰게 될 소싱 도구를 구경합니다.

🔄 재고 연동 — 품절 사고를 막아줍니다

주문을 받았는데 소싱처가 품절이면 취소해야 하고, 취소는 곧 마켓 페널티입니다. 재고 연동은 소싱처의 품절·가격 변동을 주기적으로 확인해줍니다.

  1. 왼쪽 메뉴 → 게시된 상품 → 상품 선택
  2. 가격/가격 · 재고 연동 설정확인 주기(예: 6시간마다)와 총 확인 횟수(최대 99회)를 설정합니다.
  3. 기타 설정 → 재고연동 품절 정책 확인초보자는 "하나라도 품절 시 판매 중지"를 권합니다. 안전이 우선입니다.
⚠️ "6시간마다"는 정확한 예약이 아닙니다
재확인을 실제로 실행시키는 건 서버가 아니라 내 PC의 크롬 확장프로그램입니다. "서버" 방식을 골라도 "지금 하라"는 신호는 크롬에서 나갑니다. 그래서 크롬이 꺼져 있으면 어떤 방식을 골랐든 재수집이 멈추고, 다음에 크롬을 켤 때까지 밀립니다. 재고 연동을 제대로 쓰려면 크롬을 계속 켜두는 게 가장 중요합니다.

처음 보는 단어 15개

매뉴얼과 화면에 계속 나오는 단어들입니다. 뜻만 알아도 훨씬 수월해집니다.

프리셋
수집할 때 자동으로 적용되는 편집 규칙 묶음. 상품명·가격·배송·마켓 설정이 담깁니다.
SKU
옵션 조합 하나하나를 가리키는 단위. "빨강-M"이 하나의 SKU입니다.
크레딧
서버 수집과 AI 기능을 쓸 때 차감되는 포인트. 브라우저 수집은 크레딧이 들지 않습니다.
배대지 (배송대행지)
해외 물건을 대신 받아 국내로 보내주는 현지 창고. 이용료가 원가에 포함됩니다.
MOQ
최소 주문 수량. 1688 같은 도매처는 "10개 이상 구매" 같은 조건이 붙어 있습니다.
관부가세
해외 물품에 붙는 관세와 부가세. 구매대행은 보통 구매자 부담으로 설정합니다.
썸네일 (대표이미지)
검색 결과에 뜨는 첫 번째 이미지. 클릭률을 결정합니다.
옵션 이미지
색상·사이즈를 고를 때 바뀌는 이미지. 설정하면 구매 전환율이 올라갑니다.
마진율
원가 대비 남기는 비율. 마켓 수수료를 포함해서 잡아야 실제로 남습니다.
계산식
원가에서 판매가를 자동으로 만들어내는 수식. 프리셋 안에 저장됩니다.
KC 인증
국내 안전 인증. 해외구매대행은 구매자 개인 사용 목적이라 대상이 아니지만, 13세 미만 어린이 제품은 예외입니다.
작업 큐
업로드 요청이 순서대로 처리되는 대기줄. 진행 상태와 에러 원인을 볼 수 있습니다.
재고 연동
소싱처의 품절·가격 변동을 주기적으로 확인하는 기능. 크롬이 켜져 있어야 돕니다.
그룹상품
여러 상품을 하나로 묶어 올리는 스마트스토어 전용 형태.
금지어 · 대체어
상품명에서 자동으로 지우거나 바꿔줄 단어 목록. 마켓 등록 거부를 줄여줍니다.
